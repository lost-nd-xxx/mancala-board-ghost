# うかマンカラ

## これはなに？

伺かゴーストとマンカラ（カラハ）を遊ぶための台ゴーストです。

以下の対戦形式に対応しています。

* 台       vs ユーザ   - 台の内蔵AIと一人で対戦
* ユーザ   vs ゴースト - 対応ゴーストを相手にユーザが対戦
* ゴースト vs ゴースト - 対応ゴースト同士が対戦

ルールの説明はゴースト内にありますので、そちらをご覧ください。


## 対戦の始め方

1. 台を起動する
2. 必要に応じて、対戦したいゴーストを呼び出しておく
3a. 台をダブルクリックし、対局を開始する
3b. ゴーストと対局する場合は、台を対局待機状態にし、ゴースト側に対局を申し込んでもらう


## 対応ゴーストのサンプル

対応ゴーストの実装見本として、以下の2体を配布しています。

* うかマンカラをやるこはく - [配布URL](https://github.com/lost-nd-xxx/mancala-player-amber)
* うかマンカラをやるアメジスト - [配布URL](https://github.com/lost-nd-xxx/mancala-player-amethyst)

ゴースト同士の対戦を試したい場合はこちらをお使いください。

対応ゴーストの作り方は同梱の [mancala_protocol_for_developers.txt](mancala_protocol_for_developers.txt) を参照してください。
