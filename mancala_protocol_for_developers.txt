============================================================
 うかマンカラ  対応ゴースト作者向け プロトコル仕様書
============================================================

「うかマンカラ」は、マンカラ（カラハ）を遊ぶための台ゴーストです。
他のゴースト（以下「対応ゴースト」）は raiseother を介して対局に参加できます。

このドキュメントは、対応ゴーストを実装する作者向けに、
台ゴーストとやりとりするイベントの内容をまとめたものです。

台ゴースト名（raiseother の宛先）: うかマンカラ

------------------------------------------------------------
 0. 通信の基本
------------------------------------------------------------

通信はすべて SSP の raiseother コマンドで行います。

  \![raiseother,宛先ゴースト名,イベント名,R0,R1,R2,...]

・台ゴーストへ送る場合の宛先は「うかマンカラ」固定です。
・台ゴーストから送られてくる場合の宛先は、対応ゴースト側が
  OnMancalaRequestGame の R0 で名乗った名前になります。
  （＝ R0 には、自分宛ての raiseother を受け取れるゴースト名を指定してください）

★ カンマを含む値（盤面文字列など）は必ずダブルクォートで囲んで送られます。
  受信時、Reference にはダブルクォートを除いた値が入ります。
  例: \![raiseother,○○,OnMancalaStateUpdate,"0,0,2,0,1,0,18,0,1,1,0,1,0,24",your_turn,losing]
      → Reference[0] = 0,0,2,0,1,0,18,0,1,1,0,1,0,24
        Reference[1] = your_turn
        Reference[2] = losing

------------------------------------------------------------
 1. 盤面の定義
------------------------------------------------------------

穴の総数 14、石の総数 48。各小穴に4個ずつ、ストアは0個から開始。

  インデックス  0〜5  : 先手(first)の小穴
  インデックス  6     : 先手のストア
  インデックス  7〜12 : 後手(second)の小穴
  インデックス 13     : 後手のストア

物理配置イメージ（画面上＝後手、下＝先手）:

  後手 ←  [12][11][10][ 9][ 8][ 7]
  [13]                            [6]
  先手 →  [ 0][ 1][ 2][ 3][ 4][ 5]

石の配布はインデックス昇順に巡回（0→1→…→13→0）。
相手のストアはスキップします（先手は13を、後手は6を飛ばす）。

ルール要点:
  ・連続手番 : 最後の石が自分のストアに入ったら、もう一度手番を得る。
  ・取り込み : 最後の石が自分の「空だった小穴」に入り、かつ正面の相手の穴に
               石があるとき、両穴の石を全て自分のストアへ移す。
  ・正面対応 : 先手 i ↔ 後手 (12 - i)
  ・終了     : どちらかの全小穴が空になったら終了。残った石は各自のストアへ。
               ストアの多い方が勝ち。同数は引き分け。

盤面シリアライズ形式:
  インデックス0〜13の石数をカンマ区切りにした文字列。
  初期状態の例 : 4,4,4,4,4,4,0,4,4,4,4,4,4,0

------------------------------------------------------------
 2. 参加方法の種別（重要）
------------------------------------------------------------

対応ゴーストは OnMancalaRequestGame の R2 で「AI種別」を申告します。
これによって、対局中に「誰が手を決めるか」が変わります。

  own_ai
      対応ゴースト側が自前のAIで手を決めます。
      自分の手番のたびに OnMancalaMove を送って着手してください。

  host_ai:easy / host_ai:normal / host_ai:hard
      手を決めるのは台ゴースト側のAIに委任します。
      対応ゴーストは OnMancalaMove を送る必要はありません。
      台が自動で着手し、結果を OnMancalaStateUpdate で通知します。

いずれの種別でも、盤面通知（OnMancalaGameStart / OnMancalaStateUpdate /
OnMancalaGameEnd / OnMancalaGameVoid）は対応ゴーストへ送られます。
own_ai でなくても通知は来るので、台の進行に合わせて演出できます。

------------------------------------------------------------
 3. 対局フロー
------------------------------------------------------------

凡例:  [送信] = 対応ゴースト → 台ゴースト
       [受信] = 台ゴースト → 対応ゴースト

  (1) 参加
      [送信] OnMancalaRequestGame
             → 台が受付・先後決定・盤面初期化
             （台が「参加待ち」状態のときのみ受け付けられる）

  (2) 開始
      [受信] OnMancalaGameStart
             → 自分の先後と対戦相手が通知される

  (3) 自分の手番（own_ai の場合のみ）
      [送信] OnMancalaMove
             → 無効手なら [受信] OnMancalaError が返る
             → 成立すると [受信] OnMancalaStateUpdate（更新後の盤面）

  (4) 相手の手番 / 台AIの手番 / 連続手番
      → 台が処理し、手番が確定したところで
        [受信] OnMancalaStateUpdate が届く

  (5) 終了
      [受信] OnMancalaGameEnd   … 決着
        または
      [受信] OnMancalaGameVoid  … 無効試合
             （タイムアウト・投了による中断）

  ※ (3)(4) は対局が終わるまで交互に繰り返されます。

注意:
  ・台ゴーストが「参加待ち」状態でないときに OnMancalaRequestGame を送ると、
    OnMancalaError（not_waiting）が返ります。
  ・own_ai の手番には5分のタイムアウトがあります。時間内に OnMancalaMove が
    来ないと OnMancalaGameVoid（無効試合）になります。

------------------------------------------------------------
 4. 対応ゴースト → 台ゴースト（送信するイベント）
------------------------------------------------------------

宛先はすべて「うかマンカラ」。

● OnMancalaRequestGame  … 対局参加リクエスト
   R0 : あなたのゴースト名（台からの raiseother 宛先に使われる名前）
   R1 : 呼び名（手番表示などで使われる表示名。省略時は R0 を使用）
   R2 : AI種別  own_ai / host_ai:easy / host_ai:normal / host_ai:hard
   R3 : 先後希望  first / second / any

   送信例:
   \![raiseother,うかマンカラ,OnMancalaRequestGame,うかマンカラをやるこはく,こはく,own_ai,first]

● OnMancalaMove  … 着手（own_ai のときのみ使用）
   R0 : あなたのゴースト名（OnMancalaRequestGame の R0 と同じ名前）
   R1 : 着手する穴インデックス
        （あなたが先手なら 0〜5、後手なら 7〜12）

   ★ R0 には必ず参加時(OnMancalaRequestGame)の R0 と同じ名前を入れてください。
     台はこの名前で送信元を識別します（SHIORI の Sender ヘッダは使いません）。

   送信例:
   \![raiseother,うかマンカラ,OnMancalaMove,うかマンカラをやるこはく,3]

● OnMancalaResign  … 投了
   R0 : あなたのゴースト名（OnMancalaRequestGame の R0 と同じ名前）

   送信例:
   \![raiseother,うかマンカラ,OnMancalaResign,うかマンカラをやるこはく]

------------------------------------------------------------
 5. 台ゴースト → 対応ゴースト（受信するイベント）
------------------------------------------------------------

● OnMancalaGameStart  … 先後通知＋対戦相手情報（対局開始時）
   Reference[0] : first / second  … あなたがどちらか
   Reference[1] : 対戦相手の呼び名（表示名）
   Reference[2] : 対戦相手のゴースト名（raiseother名）
                  相手が OnMancalaRequestGame 経由で参加したゴーストなら、
                  そのゴースト名が入ります（AI種別が host_ai:* でも入ります）。
                  相手が人間ユーザ、または台が用意した対戦相手
                  （メニューからの「台AIと対戦」など）の場合は空文字（""）。

● OnMancalaStateUpdate  … 盤面状態通知（手番が確定するたび）
   Reference[0] : 盤面状態（カンマ区切り14穴の石数）
   Reference[1] : 手番ステータス
                    your_turn          … あなたの手番
                    your_bonus_turn    … あなたの連続手番
                    opponent_turn      … 相手の手番
                    opponent_bonus_turn… 相手の連続手番
   Reference[2] : 優勢情報（あなたから見た判定）
                    winning … ストア差 +3以上
                    losing  … ストア差 -3以上
                    even    … それ以外

   own_ai の場合、Reference[1] が your_turn / your_bonus_turn のときに
   OnMancalaMove で着手してください。

● OnMancalaGameEnd  … 決着通知
   Reference[0] : win / lose / draw  … あなたから見た結果
   Reference[1] : 最終盤面状態（カンマ区切り14穴）

● OnMancalaGameVoid  … 無効試合通知
   引数なし。タイムアウトまたは投了による中断時に送られます。
   この対局は無効として扱ってください（勝敗はつきません）。

● OnMancalaError  … エラー通知（リクエストや着手が拒否されたとき）
   Reference[0] : エラー種別
                    invalid_move      … 無効な穴（相手の穴・空の穴・範囲外）
                    not_your_turn     … 手番外での着手
                    game_not_started  … 対局が開始されていない
                    game_in_progress  … 対局中のためリクエストを受け付けられない
                    not_your_game     … この対局の参加者ではない
                    not_waiting       … 台が参加待ち状態ではない

------------------------------------------------------------
 6. 実装のヒント
------------------------------------------------------------

・最小実装（own_ai）の流れ:
   1) ユーザ操作などをきっかけに OnMancalaRequestGame を送る
   2) OnMancalaGameStart で自分の先後を覚える
   3) OnMancalaStateUpdate を受け、Reference[1] が your_turn(_bonus) なら
      盤面 Reference[0] を見て着手を決め、OnMancalaMove を送る
   4) OnMancalaGameEnd / OnMancalaGameVoid で対局終了

・台に手を任せたいだけ（自前AI不要）なら R2 を host_ai:* にして
   OnMancalaRequestGame を送るだけでOK。あとは通知を受けて演出するだけです。

・盤面文字列は受信時にダブルクォートが外れた状態で届きます。
   "," で split すれば14要素の石数配列になります。

・先後決定ルール（R3同士の突き合わせ）:
     first  vs second → 希望通り
     first  vs any    → first希望側が先手
     second vs any    → second希望側が後手
     first  vs first  → ランダム
     second vs second → ランダム
     any    vs any    → ランダム
